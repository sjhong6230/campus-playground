# 공개 운영 위험 검토 기록

확인일: 2026-10-30. 대한민국에서 개인이 비영리 단순 공개한다는 전제의 기술·표현 점검입니다. 법률 의견서, 권리자 허락, 게임물관리위원회 확인서가 아닙니다.

## 확인한 사실과 이번 조치

- 운영자는 광고·후원·유료 판매 없이 무료 공개를 유지한다고 확인했습니다.
- 배포 소스에는 회원가입, 채팅, 게시물 업로드, 광고 SDK, analytics 또는 점수 전송 코드가 없습니다. 점수·화질은 localStorage에만 저장합니다. GitHub 호스팅의 접속 기록과는 구분합니다.
- 사진, 위성지도 타일, 교표, 외부 폰트·음악 파일을 게임 asset으로 포함하지 않습니다. Procedural geometry·texture·sound를 사용하고 참고 자료는 학교별 문서로 분리합니다. 이것만으로 모든 건축물 표현의 권리가 해결되는 것은 아닙니다.
- 제목·검색 설명·선택 화면·게임 화면에 비공식 모형임을 명시합니다. 게임 브랜드와 학교 약칭을 구분하고 모형에 대한 행동으로 표현합니다. 실제 사람은 등장하지 않습니다.
- 시작 화면과 모든 단독 HTML에서 공통 안내, 개인정보 설명, 권리 문의 및 Three.js MIT 전문을 열 수 있습니다. 이용자의 법적 권리 포기나 운영자의 포괄적 면책에 동의를 요구하지 않습니다.
- CSP의 connect-src를 none으로 설정해 게임의 임의 네트워크 데이터 전송을 제한합니다. 외부 링크는 사용자가 직접 열 때만 이동하며 referrer를 보내지 않습니다. 최초 HTML 요청과 GitHub 호스팅 로그까지 차단한다는 의미는 아닙니다.
- 권리 문의는 저장소의 공개 GitHub Issues로 받습니다. 개인정보·비공개 증빙 업로드를 요구하지 않습니다. 개인 연락처는 임의로 추정하거나 게시하지 않았습니다.

## 등급분류: 비영리라고 확정 면제 표시는 하지 않음

[게임산업진흥에 관한 법률 제21조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025570463)는 원칙적인 등급분류 의무와 비영리 게임 예외를 규정합니다. 열람한 조문은 2025-10-23 시행본입니다.
[시행령 제11조의3](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=171675)은 개인·동호회 등의 국내 단순 공개 창작물을 규정하며, 예외 해당 여부를 위원회에 미리 확인할 수 있게 합니다. 열람한 시행령은 2026-03-24 시행본입니다.

현재 운영 방식은 예외 검토와 관련된 사실이지만 해당 여부를 개발자가 확정하지 않습니다. 건물 붕괴·폭발·화면 flash 등 실제 콘텐츠와 운영 형태를 설명하여 게임물관리위원회에 확인하는 것이 남은 절차입니다. 전체이용가 또는 면제 확인을 받은 것처럼 표시하지 않습니다. 광고·후원·유료화·경품·이용자 콘텐츠를 도입하기 전에는 다시 검토합니다.

## 명칭·건축물·자료

학교 이름의 설명적 사용과 비공식 표시만으로 분쟁 가능성이 사라지지는 않습니다. 학교·교육청의 허락이나 제휴를 주장하지 않으며, 실제 교표와 학생·교직원 정보는 사용하지 않습니다. 학교나 권리자가 구체적인 문제를 제기하면 해당 모형의 일시 비공개, 명칭 변경 또는 사용 허락 확인을 개별적으로 검토합니다.

[저작권법 제35조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029423821)는 공개 장소의 미술저작물 등의 복제 이용과 예외를 규정합니다. 열람한 조문은 2026-08-11 시행본입니다. 캠퍼스가 일반 공중에게 개방되었는지, 개별 건축물·미술품의 보호 여부, 사진·도면의 별도 권리와 이용 방식 등은 각 사안에 따라 검토해야 합니다. 공개 인터넷 자료라는 이유만으로 자유 이용을 단정하지 않습니다.

## 초기 코드와 SMASH

[SMASH의 현재 LICENSE](https://github.com/Hong-Iron/SMASH/blob/main/LICENSE)는 코드·그림·화면 디자인의 복제·수정 배포를 제한하고 독립적인 재구현은 구분합니다. Inspired by 표시는 이용 허락을 대신하지 않습니다.

운영자는 SMASH 같은 게임을 보고 AI에 제작을 요청했고, AI가 원작의 재배포 제한을 설명한 뒤 새로 작성했을 것으로 기억한다고 답했습니다. 이는 독립 작성의 확정 증거가 아닙니다. 현재 확인 가능한 저장소는 기존 앱을 모듈로 옮긴 커밋부터 시작하므로 최초 생성 과정 전체를 입증하지 못합니다. 생성 대화·작업 기록을 보존하고, 실제 가져온 코드·CSS·이미지가 있다면 그 부분의 허락 확인 또는 독립 재구현이 필요합니다. 이번 변경으로 원작 권리 문제가 완전히 해결됐다고 표시하지 않습니다.

Three.js는 기존 MIT 고지를 파일과 배포 HTML 안에 유지합니다. 프로젝트 전체에 새 라이선스를 임의로 부여하지 않았습니다.

## 개인정보 안내의 범위

[GitHub Pages 공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)는 로그인 여부와 관계없이 보안 목적으로 방문자 IP를 기록한다고 설명합니다. 게임 자체가 정보를 전송하지 않는다는 설명과 호스팅의 처리를 구분해 공개했습니다. [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)도 함께 참고합니다.

별도 문의 이메일·폼, analytics, 광고, 로그인·게시판을 추가하면 실제 처리 흐름에 맞춰 개인정보 안내 및 필요한 법적 절차를 다시 준비해야 합니다. 현재는 제3자 서비스인 GitHub Issues에 공개 가능한 내용만 받습니다.

## 운영자가 남겨둘 확인 사항

1. 초기 생성 대화와 사용한 모든 외부 자료의 출처·허락 기록을 보관합니다.
2. 게임물관리위원회에 실제 서비스의 비영리 등급분류 예외 해당 여부를 확인합니다. 이 작업에서는 기관에 문의를 전송하지 않았습니다.
3. 권리 요청에 대응할 운영자를 정하고 GitHub Issues를 확인합니다. 즉시 자동 처리나 응답 기한을 약속하지 않습니다.
4. 구체적인 분쟁 또는 수익화 전에 국내 변호사에게 실서비스·소스·자료를 제시해 검토받습니다.
5. 특정 학교 공개를 중단해야 할 때는 등록 목록에서 제외하고 단독 HTML을 포함한 배포물을 새로 생성합니다. 이미 다운로드·공유된 사본과 검색 캐시는 별도 회수가 필요할 수 있습니다.
